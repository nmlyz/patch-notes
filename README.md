A single-file Python program that writes one real-life patch note to `entry.txt`: a software-style changelog entry for a bug in human biology, where hair migrates from the scalp to the ears and nose after age 40. It uses only the Python standard library, needs no network, and is fully deterministic: every run writes the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes `entry.txt` to the output directory (or `/output` when `MAKEFUN_OUTPUT_DIR` is not set).
